# Progenitor branding

| File | Size | Use |
|---|---|---|
| `progenitor-stamp-64.png` | 64×64, transparent outside the ring | The stamp for a mod's 256×256 Thunderstore icon. Paste it unscaled at (184, 184). |
| `progenitor-stamp-512.png` | 512×512, transparent outside the ring | Large previews only (a README image or a page banner). Never scale it down onto an icon; use the 64×64 file, which is the size the stamp was checked at. |
| `../packaging/thunderstore/icon.png` | 256×256 | Progenitor's own Thunderstore icon. |

The stamp is optional. Mods built on Progenitor may use it to show that they run on Progenitor; it does not mean Progenitor reviewed or endorses the mod. Use it unaltered: no recoloring, rotating, cropping or resampling.

Placement, the corner to keep free, and a compositing snippet are in [Publishing a mod](../docs/publishing.md#4-the-progenitor-stamp-optional).

## Provenance

All Progenitor artwork was made for this project with AI image tools. No third-party art or stock imagery was used.

| Artwork | How it was made |
|---|---|
| Mods menu background (`src/Progenitor.Core/Ui/Assets/mods-background.png`) | Generated for Progenitor with an AI image generator. |
| Thunderstore icon (`packaging/thunderstore/icon.png`) | Derived from the Mods menu background with an AI image tool. |
| Stamp (`progenitor-stamp-64.png`, `progenitor-stamp-512.png`) | Derived from the Mods menu background with an AI image tool. |
